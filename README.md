# Blackjack CLI Game

A simple terminal-based Blackjack (21 点) game written in Python.

## Requirements
- Python 3.9 or newer

## How to Play
1. Run the game:
   ```bash
   python blackjack.py
   ```
2. You will start with two cards and see one of the dealer's cards.
3. Choose to **hit** (draw another card) or **stand** to keep your current total.
4. The dealer draws until reaching at least 17. The closest to 21 without going over wins.

Enjoy the game!
